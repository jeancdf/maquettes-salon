# Maquettes — site de salon de coiffure

Deux maquettes de site vitrine pour un salon fictif (« l’épi »), à présenter aux prospects :

- **Essentiel — 690 € HT** : site d’une page (`essentiel.html`)
- **Complet — 1 190 € HT** : site de 5 pages, page d’accueil représentée (`complet.html`)

`index.html` permet de basculer instantanément de l’une à l’autre (boutons, touches `1` / `2` ou flèches ←/→, liens directs `#essentiel` et `#complet`).

Salon fictif : tarifs indicatifs, coordonnées entre crochets à personnaliser.
